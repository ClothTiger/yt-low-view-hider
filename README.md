# yt-low-view-hider
Violent Monkey script to hide YT videos with a low view count

Made for Brave - no clue if it works for other browsers, but why would you use another one?!

INSTALL

Just open https://raw.githubusercontent.com/ClothTiger/yt-low-view-hider/main/yt-low-view-hider.user.js

and it should add it to your ViolentMonkey extension.
